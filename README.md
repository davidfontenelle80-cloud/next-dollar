# Next Dollar

**Personal Financial Coach** — step-by-step EN/ES budget guide built as a PWA.

Walks through 6 steps: income, housing, bills, debt, savings, allocation. Outputs Safe-to-Spend figure. Bilingual (EN/ES), dark/light/system theme, offline-capable.

## Run locally

Open `index.html` in a browser, or serve with any static file server.

## Deploy

Push to `main` branch — GitHub Pages serves from root.
